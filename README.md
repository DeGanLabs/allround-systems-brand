# Allround Systems — Brand Identity Guidelines

Public brand kit for **Allround Systems UG**.

**Live:** https://deganlabs.github.io/allround-systems-brand/

## Contents

- `index.html` — brand identity guidelines (LADS TV–style layout)
- `svg/` — mark, lockups, favicon, app icon
- `tokens.css` — color tokens
- `trace_mark.py` — rebuild SVGs from `_source-mark.png` (traced AS + geometric ring)

## Colors

| Token | Hex | Use |
|-------|-----|-----|
| Navy | `#0B243B` | structure, text, mark |
| Signal | `#F19E38` | accent ring segment only |
| Paper | `#F5F3ED` | light surfaces |
